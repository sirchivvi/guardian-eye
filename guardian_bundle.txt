# GuardianEye — Standing Agent Rules

These rules apply to every phase and every agent or contributor working on
the GuardianEye project.  Read them before making any change.

---

## 1. Modalities

GuardianEye has exactly **two modalities**: **image** and **audio**.

- Video is handled by decoding frames and routing them through the **image branch**.
- There is no separate video branch.

---

## 2. Approved technology stack

| Tool | Version constraint |
|---|---|
| Python | 3.11 |
| PyTorch | ≥ 2.3 |
| torchaudio | ≥ 2.3 |
| scikit-learn | ≥ 1.5 |
| pandas | ≥ 2.2 |
| PyYAML | ≥ 6.0 |
| Pydantic | ≥ 2.7 |
| pytest | ≥ 8.2 |
| Ruff | ≥ 0.4 |

**Ask before adding any dependency not listed above.**

---

## 3. Configuration

- All hyperparameters and filesystem paths **must** be read from `config.yaml`.
- Never hard-code absolute paths.
- Path precedence: CLI argument > `DATA_ROOT`/`RESULTS_ROOT` env vars > `config.yaml`.
- Use `src.config.load_config()` and `src.config.resolve_paths()`.

---

## 4. Phased development

- Work **one phase at a time**.
- Stop after each phase and provide a summary of:
  - Files changed or created
  - Commands to run
  - Actual test and lint results (or `NOT YET RUN` with explanation)
- **Never begin the next phase without explicit approval.**

---

## 5. Metrics and results integrity

- **Never invent, fabricate, or estimate metrics.**
- If data or trained models are unavailable, report exactly:
  > `NOT YET RUN — <reason>`
- Do not run evaluations on placeholder or synthetic data and present the
  numbers as if they reflect real dataset performance.

---

## 6. Dataset split discipline

- Assign **train / val / test splits before creating any image–audio pairs**.
- **Never create cross-split pairs** (a training image paired with a test
  audio clip, etc.).
- Split fractions are defined in `config.yaml`:
  `train = 0.70`, `val = 0.15`, `test = 0.15`.

---

## 7. Prohibited synthetic data

- **Never synthesise vehicle images.**  Vehicle imagery is scarce; inventing
  examples would invalidate evaluation results.
- ESC-50 thunderstorm, wind, and rain clips **remain labelled `background`**
  with a `noise_tag` of `thunder_wind`.  They are **never relabelled as
  `gunshot`**.

---

## 8. Dataset access

- **Never download datasets automatically.**
- Read only from the configured `data/raw/` directory.
- If a dataset is missing, log a clear warning and continue or stop — never
  fabricate data.

---

## 9. What must never be committed

| Forbidden | Reason |
|---|---|
| Dataset files | Size and licence |
| Model weights (`.pt`, `.pth`, `.bin`) | Size |
| `.env` files | Secrets |
| API keys, tokens, passwords | Security |
| Generated archives (`*.tar.gz`) | Size |

---

## 10. Code quality

Every public function and class **must** have:
- **Type hints** on all arguments and the return value.
- A **docstring** (Google or NumPy style).
- At least one **unit test** exercising the main behaviour.
- **Logging** (via `logging`) instead of `print()` in application code.

---

## 11. Compute environment

- Local development (Windows laptop, CPU-only) supports tests, linting,
  configuration validation, and smoke tests only.
- All substantive model training and evaluation runs on **Google Colab** or
  **Kaggle**.
- Tests must **never require CUDA**.  Use `monkeypatch` or conditional skips
  for GPU-specific behaviour.

---

## 12. Checkpointing

All training modules **must** use `src.checkpoint`:
- Call `save_checkpoint()` after every epoch.
- Call `find_latest_checkpoint()` on startup to resume automatically.
- Never start training without checking for an existing checkpoint.
- Checkpoint state must include: `model_state`, `optimizer_state`, `epoch`,
  `config`, `seed`, and optionally `scheduler_state` / `scaler_state`.

---

## 13. Destructive or elevated commands

**Always ask before executing** commands that:
- Delete files or directories
- Install system packages (outside pip)
- Modify the Git history

---

## 14. Academic scope disclaimer

GuardianEye is an **academic proof of concept**.  The public datasets used do
not contain real, time-aligned poaching incidents.  Fusion evaluation relies
on **synthetic image–audio pairs**.  Results must not be presented as a
validated field alert system.

===== docs\bda.md =====  
# Big Data Analytics (BDA) Module — GuardianEye

> **Design and implementation documentation for Phase 3 Big Data Analytics.**

The GuardianEye BDA module (`src/bda/`) provides scalable data-aggregation pipelines designed for large-scale wildlife monitoring and sensor networks. It implements Hadoop-Streaming-compatible MapReduce jobs, an automated local streaming engine for local and CI execution, optional PySpark pipelines, Hive DDL schemas, and verification self-checks.

---

## 1. Architecture Overview

In an anti-poaching sensor deployment, acoustic sensors and camera traps generate high-volume distributed logs and manifests. The BDA architecture aggregates raw metadata, scenario combinations, and evaluation metrics across seeds and folds without requiring manual spreadsheet manipulation or single-threaded loops.

```
                    ┌───────────────────────────────┐
                    │ Raw Manifest / Scenarios /    │
                    │ Evaluation Metrics            │
                    └───────────────┬───────────────┘
                                    │
                                    ▼
                      Hadoop Streaming / Local Sort
                    ┌───────────────────────────────┐
                    │ Mapper: emits key-value pairs │
                    │ Sort: groups keys (composite) │
                    │ Reducer: aggregation / stats  │
                    └───────────────┬───────────────┘
                                    │
            ┌───────────────────────┴───────────────────────┐
            ▼                                               ▼
┌───────────────────────┐                       ┌───────────────────────┐
│ CSV Aggregations:     │                       │ Optional Spark /      │
│ - class_counts.csv    │                       │ Parquet Ingestion     │
│ - scenario_counts.csv │                       │ - manifest.parquet    │
│ - metric_summary.csv  │                       │ - class_weights.pq    │
│ - bda_status.json     │                       │ - audio_features.pq   │
└───────────────────────┘                       └───────────────────────┘
```

---

## 2. Hadoop Streaming MapReduce Jobs

Each mapper and reducer is executable as a standalone module via stdin/stdout, making it directly consumable by the standard `hadoop jar hadoop-streaming-*.jar`:

### 2.1 Class Counts Pipeline
- **Mapper** (`src/bda/mapper_class.py`):
  Reads manifest CSV lines (`path,modality,source,label,...`) and emits:
  ```
  modality\tsource\tlabel \t 1
  ```
  Missing or empty label fields are skipped (never converted into negative/background examples).
- **Reducer** (`src/bda/reducer_sum.py`):
  Groups pre-sorted keys and sums the integer counts, producing:
  ```
  modality\tsource\tlabel\t<count>
  ```

### 2.2 Scenario Counts Pipeline
- **Mapper** (`src/bda/mapper_scenario.py`):
  Reads pairing CSV lines (`split,scenario,suspicious,risk,...`) and emits:
  ```
  split\tscenario\tsuspicious\trisk \t 1
  ```
- **Reducer** (`src/bda/reducer_sum.py`):
  Aggregates counts per scenario tuple, producing:
  ```
  split\tscenario\tsuspicious\trisk\t<count>
  ```

### 2.3 Evaluation Metric Summary Pipeline
- **Mapper** (`src/bda/mapper_metric.py`):
  Reads JSON metric records (`{"method": ..., "condition": ..., "metric": ..., "value": ...}`) and emits:
  ```
  method\tcondition\tmetric \t <value>
  ```
  Undefined metrics (`value: null`, zero-denominator situations) are omitted.
- **Reducer** (`src/bda/reducer_metric.py`):
  Computes sample statistics for each key:
  - $n$: sample count
  - $\text{mean} = \frac{1}{n} \sum x_i$
  - $\text{sample\_std} = \sqrt{\frac{1}{n-1} \sum (x_i - \text{mean})^2}$ when $n \ge 2$; left empty when $n < 2$.

---

## 3. Streaming Engine & Execution Detection

`src/bda/stream.py` provides an execution engine that automatically chooses between Hadoop Streaming and a local Python fallback:

1. **Hadoop Detection**: Checks if `HADOOP_HOME` is set, `hadoop` binary exists on PATH, and `hadoop-streaming-*.jar` is located.
2. **Local Fallback (`python_streaming_local`)**: Simulates the MapReduce pipeline by executing the mapper, sorting key-value pairs in memory, and piping them into the reducer.
3. **Engine Logging**: The engine name (`hadoop_streaming` or `python_streaming_local`) is recorded in logs and in `bda_status.json`.

---

## 4. Optional PySpark Jobs

`src/bda/spark_jobs.py` provides DataFrame transformations for larger scale datasets:

1. **`manifest_to_parquet`**: Ingests manifest CSV into compressed Parquet.
2. **`compute_class_weights`**: Calculates balanced class weights per modality:
   $$w_c = \frac{N}{k \cdot n_c}$$
   Guarded against division by zero if $k=0$ or $n_c=0$.
3. **`compute_audio_features`**: Uses a `@pandas_udf` to compute 64-band log-mel energy summaries across worker nodes using `torchaudio`.

**Honesty Policy on PySpark**:
If `pyspark` is not installed, all Spark routines gracefully return `{"status": "NOT YET RUN", "reason": "pyspark not installed"}`. The system never fakes Spark completion.

---

## 5. Hive DDL Schemas

`src/bda/schema.hql` provides Hive external table definitions for warehouse analytics:
- `manifest`: external table pointing to raw manifest CSV.
- `class_counts`: table for class distribution summaries.
- `scenario_counts`: table for synthetic pair scenario distributions.
- `metric_summary`: table for multi-seed performance statistics.
- `manifest_parquet`: Parquet representation of the manifest.
- `class_weights`: Parquet table of computed inverse-frequency weights.
- `audio_features`: Parquet table with 64-band log-mel feature arrays.

*Note: `schema.hql` serves as schema documentation and is not executed in local pipelines.*

---

## 6. CLI and Makefile Integration

### Run BDA Self-Check (on built-in fixtures)
```bash
make bda-check
# or
python scripts/run_bda.py --self-check
```
Validates mapper and reducer pipelines against golden fixtures (`tests/fixtures/bda/`) with tolerance-based numeric comparison.

### Run BDA on Project Manifests
```bash
make bda
# or
python scripts/run_bda.py --mode all
```
Modes available:
- `--mode class_counts`: Run class counts job.
- `--mode scenarios`: Run scenario pairing distribution job.
- `--mode metrics`: Run evaluation metrics summary job.
- `--mode spark`: Run PySpark jobs (if installed).
- `--mode all`: Run all streaming and Spark jobs.

### Status Tracking
All executions write atomic status output to `results/bda/bda_status.json`. If inputs are unpopulated (e.g. before downloading real raw data), the pipeline exits cleanly with `NOT YET RUN`.

## 3. Antigravity: how to use it (beginner section)

Antigravity is Google's agent-first coding environment, launched in November 2025. It is built on a heavily modified VS Code fork and has two main views: the familiar **Editor** and the **Agent Manager** (a mission-control screen where you give tasks to agents and review results). Details change quickly, so if a menu looks different in your version, trust your screen and the docs at antigravity.google/docs.

### 3.1 Install and first launch
1. Download from antigravity.google/download (Windows .exe, macOS .dmg, Linux .deb/.rpm).
2. At setup, you can **import settings and extensions from VS Code or Cursor**, or start fresh.
3. Sign in with the Google account that holds your Pro plan.
4. Open your project folder (`File > Open Folder`), not a single file. The agent works on the open workspace.

### 3.2 The two views
| View | Use it for |
|---|---|
| Agent Manager | Start tasks, run several agents in parallel, read their plans and results (called Artifacts), approve or comment |
| Editor | Read and edit code yourself, run the terminal, use Git, use extensions |
Use the switch button in the Agent Manager to jump to the Editor and back.

### 3.3 Modes: Fast vs Planning
- **Planning**: the agent writes an implementation plan first, then builds. Use this for every GuardianEye phase.
- **Fast**: quick edits and small fixes (rename a variable, fix a typo, add a test).

### 3.4 Artifacts (how you review the agent)
Agents produce reviewable artifacts: a plan, a task list, a walkthrough of what changed, screenshots and browser recordings. **Read the plan before approving.** If something is wrong, comment on the plan and ask for a revision instead of letting it build the wrong thing.

### 3.5 Safety settings (important, set these first)
Agents can run terminal commands and edit files. In Settings, find the agent permissions / terminal execution options and:
- Keep terminal commands on **ask before running** (review-driven) until you trust the setup.
- Never approve commands that delete folders, reformat disks, or touch paths outside the project.
- Keep the browser agent on an allowlist if the setting is offered.
- Check **Settings > AI Credits** (or the plan page) to see how much of your Pro allowance you use; heavy runs on big models drain it faster. Use Fast mode for small edits.

### 3.6 Rules, workflows, skills (customising the agent)
| Thing | What it is | Where it lives |
|---|---|---|

## 6. Data download, step by step (the five datasets)

Create the folders:
~~~bash
mkdir -p data/raw/{birdsai,cct,serengeti,belize,vietnam,esc50} data/processed results
~~~
Do the downloads yourself. The pipeline then reads only from `data/raw/`.

### 6.1 BIRDSAI (thermal aerial, image branch)
1. Open https://lila.science and find **BIRDSAI**.
2. Download the **real** training and test archives (frames or videos plus annotation files). Start with real data; the synthetic part is optional.
3. Unzip into `data/raw/birdsai/`.
4. Annotations are MOT-style rows; per your CA4 mapping, class code **1 = human**, **0 = animal**, and a frame with no box is **empty**. If a frame has both, store it as human and write the manifest note `human_and_animal_boxes`.
5. If you get videos, decode them to frames with FFmpeg (1 frame per second is enough):
~~~bash
mkdir -p data/raw/birdsai/frames
ffmpeg -i video.mp4 -vf fps=1 data/raw/birdsai/frames/video_%05d.jpg
~~~
View label: `aerial_thermal`.

### 6.2 Caltech Camera Traps (ground camera traps)
1. On https://lila.science open **Caltech Camera Traps**. Use the benchmark subset (CCT20); its images are already downsized to 1024 pixels on a side, which saves a lot of space.
2. Download the metadata JSON (COCO Camera Traps format) first; it is small.
3. Download only a sample of images (a few thousand, balanced across empty, animal, any human or vehicle), using the base URL listed on the dataset page for your preferred cloud (GCP, Azure or AWS). The LILA collection is also mirrored as a public bucket on Source Cooperative, which you can browse without an account:
~~~bash
pip install awscli
aws s3 ls --no-sign-request s3://us-west-2.opendata.source.coop/agentmorris/lila-wildlife/
~~~

def write_unimodal_not_yet_run(run_dir: Path, seed: int, reason: str) -> None:
    """Write NOT YET RUN status JSON to run root and outputs folder."""
    status_data = {
        "seed": seed,
        "status": "NOT YET RUN",
        "reason": reason,
        "image_trained": False,
        "audio_trained": False,
        "cross_site_evaluated": False,
    }
    for p in [run_dir / "unimodal_status.json", run_dir / "outputs" / "unimodal_status.json"]:
        p.parent.mkdir(parents=True, exist_ok=True)
        with p.open("w", encoding="utf-8") as f:
            json.dump(status_data, f, indent=2)


def run_image_training_for_seed(
    cfg: GuardianEyeConfig,
    seed: int,
    device: torch.device,
    epochs: int | None = None,
    batch_size: int | None = None,
) -> int:
    """Run image branch training and evaluation for a single seed."""
    run_dir = cfg.paths.results_root / "runs" / f"seed_{seed}"
    manifest_csv = run_dir / "manifest" / "manifest.csv"
    manifest_status_file = run_dir / "manifest" / "manifest_status.json"

    # Check Phase 1 manifest status
    if manifest_status_file.exists():
        try:
            with manifest_status_file.open("r", encoding="utf-8") as f:
                manifest_status = json.load(f)
            if manifest_status.get("status") == "NOT YET RUN":
                m_reason = manifest_status.get("reason", "unpopulated")
                reason = f"Phase 1 manifest status is NOT YET RUN: {m_reason}"
                logger.warning("Seed %d: %s. Exiting cleanly.", seed, reason)
                write_unimodal_not_yet_run(run_dir, seed, reason)
                return 0
        except Exception as exc:
            logger.warning("Could not read %s: %s", manifest_status_file, exc)

    if not manifest_csv.exists() or manifest_csv.stat().st_size == 0:
        reason = "Manifest CSV is missing or empty."
        logger.warning("Seed %d: %s. Exiting cleanly.", seed, reason)
        write_unimodal_not_yet_run(run_dir, seed, reason)
        return 0

    df = pd.read_csv(manifest_csv)
    image_df = df[df["modality"] == "image"]
    if len(image_df) == 0:
        reason = "Manifest contains 0 image records."
        logger.warning("Seed %d: %s. Exiting cleanly.", seed, reason)
        write_unimodal_not_yet_run(run_dir, seed, reason)
        return 0

    train_df = image_df[image_df["split"] == "train"]
    val_df = image_df[image_df["split"] == "val"]
    test_df = image_df[image_df["split"] == "test"]

    if len(train_df) == 0:
        reason = "0 image samples assigned to train split."
        logger.warning("Seed %d: %s. Exiting cleanly.", seed, reason)
        write_unimodal_not_yet_run(run_dir, seed, reason)
        return 0

    checkpoint_dir = run_dir / "checkpoints" / "image_branch"
    outputs_dir = run_dir / "outputs"
    metrics_dir = run_dir / "metrics"

    logger.info("Training ImageEncoder for seed %d (device: %s)", seed, device)
    model, _ = train_image_model(
        train_df=train_df,
        val_df=val_df,
        data_root=cfg.paths.data_root,
        cfg=cfg,
        seed=seed,
        device=device,
        checkpoint_dir=checkpoint_dir,
        epochs=epochs,
        batch_size=batch_size,
    )

    # 1. Extract and serialize outputs for EVERY scanned image file
    logger.info("Extracting embeddings for %d image files...", len(image_df))
    image_outputs = extract_image_outputs(
        model=model,
        manifest_df=image_df,
        data_root=cfg.paths.data_root,
        device=device,
        batch_size=batch_size or cfg.image.batch_size,
    )
    save_serialized_outputs(image_outputs, outputs_dir / "image_outputs.pt")

    # 2. Evaluate model strictly on test split
    logger.info("Evaluating ImageEncoder on test split (%d samples)...", len(test_df))
    metrics = evaluate_image_model(
        model=model,
        test_df=test_df,
        data_root=cfg.paths.data_root,
        device=device,
        batch_size=batch_size or cfg.image.batch_size,
    )

    metrics_dir.mkdir(parents=True, exist_ok=True)
    metrics_file = metrics_dir / "image_metrics.json"
    with metrics_file.open("w", encoding="utf-8") as f:
        json.dump(metrics, f, indent=2)
    logger.info("Saved image metrics to %s", metrics_file)

    # Update unimodal status
    status_file = run_dir / "unimodal_status.json"
    current_status: dict[str, Any] = {}
    if status_file.exists():
        try:
            with status_file.open("r", encoding="utf-8") as f:
                current_status = json.load(f)
        except Exception:
            pass

    current_status["seed"] = seed
    current_status["status"] = "OK"
    current_status["image_trained"] = True
    for p in [status_file, outputs_dir / "unimodal_status.json"]:
        p.parent.mkdir(parents=True, exist_ok=True)
        with p.open("w", encoding="utf-8") as f:
            json.dump(current_status, f, indent=2)

    return 0


def main(argv: list[str] | None = None) -> int:
    """CLI entry point for scripts/train_image.py."""

    setup_logging(level=args.log_level)

    )

            cfg=cfg,
            seed=seed,
            device=device,
            epochs=args.epochs,
            batch_size=args.batch_size,
        )
        if code != 0:
            return code

    return 0


if __name__ == "__main__":

def _run_smoke(cfg: GuardianEyeConfig) -> None:  # noqa: F821
    """Execute a lightweight CPU smoke test using synthetic fixtures.

    This function:
    1. Logs the active smoke configuration.
    2. Generates tiny synthetic tensors (no real data required).
    3. Confirms that the config, logging, and device detection are working.
    4. Reports elapsed time.

    It does NOT train models, download datasets, or produce real metrics.

    Parameters
    ----------
    cfg:
        Validated GuardianEye configuration object.
    """
    import torch

    from src.logging_config import get_device

    logger = logging.getLogger(__name__)
    logger.info("=== SMOKE TEST MODE ===")
    logger.info(
        "Smoke settings: batch=%d epochs=%d fixture_images=%d fixture_audio=%d",
        cfg.smoke.batch_size,
        cfg.smoke.epochs,
        cfg.smoke.fixture_images,
        cfg.smoke.fixture_audio,
    )

    device = get_device()
    logger.info("Device selected: %s", device)

    start = time.perf_counter()

    # Synthetic image-like tensors  [N, C, H, W]
    fake_images = torch.randn(
        cfg.smoke.fixture_images,
        3,
        *cfg.image.input_size,
    )
    # Synthetic audio-like mel spectrogram tensors [N, 1, Mels, T]
    time_frames = int(
        cfg.audio.duration_sec * cfg.audio.sample_rate / cfg.audio.hop_length
    )
    fake_audio = torch.randn(
        cfg.smoke.fixture_audio,
        1,
        cfg.audio.n_mels,
        time_frames,
    )

    logger.info(
        "Synthetic fixtures created -- images: %s, audio: %s",
        tuple(fake_images.shape),
        tuple(fake_audio.shape),
    )

    # Simulate one epoch of trivial processing (no model, no backprop)
    for epoch in range(cfg.smoke.epochs):
        for i in range(0, cfg.smoke.fixture_images, cfg.smoke.batch_size):
            batch = fake_images[i : i + cfg.smoke.batch_size].to(device)
            _ = batch.mean()  # stand-in for a forward pass

        logger.info("Smoke epoch %d complete", epoch)

    elapsed = time.perf_counter() - start
    budget_sec = 5 * 60  # 5 minutes

    if elapsed < budget_sec:
        logger.info(
            "Smoke test PASSED -- elapsed %.2fs (budget %ds)", elapsed, budget_sec
        )
    else:
        logger.warning(
            "Smoke test EXCEEDED budget -- elapsed %.2fs (budget %ds)",
            elapsed,
            budget_sec,
        )

_DEFAULT_CONFIG_PATH = Path(__file__).parent.parent / "config.yaml"


def load_config(
    config_path: Path | str | None = None,
    *,
    data_root: Path | str | None = None,
    results_root: Path | str | None = None,
) -> GuardianEyeConfig:
    """
    Load and validate the GuardianEye configuration.

    Precedence (highest first):
    1. ``data_root`` / ``results_root`` keyword arguments (CLI overrides)
    2. ``DATA_ROOT`` / ``RESULTS_ROOT`` environment variables
    3. Values in ``config.yaml``

    Parameters
    ----------
    config_path:
        Path to the YAML configuration file.  Defaults to the
        ``config.yaml`` in the repository root.
    data_root:
        Override for ``paths.data_root`` (CLI level).
    results_root:
        Override for ``paths.results_root`` (CLI level).

    Returns
    -------
    GuardianEyeConfig
        Validated configuration object.

    Raises
    ------
    FileNotFoundError
        If the configuration file does not exist.
    pydantic.ValidationError
        If the configuration values fail validation.

    """
    cfg_path = Path(config_path) if config_path is not None else _DEFAULT_CONFIG_PATH

    if not cfg_path.exists():
        raise FileNotFoundError(f"Configuration file not found: {cfg_path}")

    with cfg_path.open() as fh:
        raw: dict[str, Any] = yaml.safe_load(fh) or {}

    # Build the config from YAML
    cfg = GuardianEyeConfig.model_validate(raw)

    # Apply env-var overrides (level 2)
    env_data = os.environ.get("DATA_ROOT")
    env_results = os.environ.get("RESULTS_ROOT")
    if env_data:
        cfg.paths.data_root = Path(env_data)
    if env_results:
        cfg.paths.results_root = Path(env_results)

    # Apply CLI-level overrides (level 1, highest)
    cfg = resolve_paths(cfg, data_root=data_root, results_root=results_root)

    return cfg


def resolve_paths(
    cfg: GuardianEyeConfig,
    *,
    data_root: Path | str | None = None,
    results_root: Path | str | None = None,
) -> GuardianEyeConfig:
    """
    Apply explicit CLI path overrides to an existing config.

    This is the highest-precedence path override layer.  Call it after
    parsing CLI arguments to apply ``--data-root`` / ``--results-root`` flags.

    Parameters
    ----------
    cfg:
        Configuration object to update (mutated in place and returned).
    data_root:
        Explicit data root path.  ``None`` means "no override".
    results_root:
        Explicit results root path.  ``None`` means "no override".

    Returns
    -------
    GuardianEyeConfig
        The same object with paths updated.

    """
    if data_root is not None:
        cfg.paths.data_root = Path(data_root)
    if results_root is not None:
        cfg.paths.results_root = Path(results_root)
    return cfg

"""
GuardianEye unimodal model architectures.

Implements:
- ImageEncoder: 4-block CNN, 128-d penultimate embedding, 4-class classifier head
  (human, vehicle, animal, empty) with opt-in ResNet-18 support.
- AudioEncoder: 4-block CNN for log-mel spectrograms (1, 64, 251), 128-d penultimate
  embedding, 2-class classifier head (background, gunshot).
"""

from __future__ import annotations

import logging

import torch
import torch.nn as nn

logger = logging.getLogger(__name__)

# Canonical class labels and indices
IMAGE_CLASSES: list[str] = ["human", "vehicle", "animal", "empty"]
IMAGE_CLASS_TO_IDX: dict[str, int] = {c: i for i, c in enumerate(IMAGE_CLASSES)}

AUDIO_CLASSES: list[str] = ["background", "gunshot"]
AUDIO_CLASS_TO_IDX: dict[str, int] = {c: i for i, c in enumerate(AUDIO_CLASSES)}


class ConvBlock(nn.Module):
    """A standard Convolution-BatchNorm-ReLU-MaxPool block."""

    def __init__(
        self,
        in_channels: int,
        out_channels: int,
        kernel_size: int = 3,
        padding: int = 1,
        pool_size: int = 2,
    ) -> None:
        super().__init__()
        self.block = nn.Sequential(
            nn.Conv2d(
                in_channels,
                out_channels,
                kernel_size=kernel_size,
                padding=padding,
                bias=False,
            ),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=pool_size, stride=pool_size),
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """Forward pass through conv, batchnorm, relu, and maxpool."""
        return self.block(x)


class ImageEncoder(nn.Module):
    """
    Image branch encoder.

    Architecture:
    - 4 Conv blocks: 3 -> 32 -> 64 -> 128 -> 256 channels.
    - Adaptive average pooling to (1, 1).
    - Linear projection to penultimate 128-d embedding.
    - Linear classification head to 4 classes (human, vehicle, animal, empty).
    - Opt-in support for pretrained ResNet-18 backbone.
    """

    def __init__(
        self,
        num_classes: int = 4,
        embedding_dim: int = 128,
        use_pretrained: bool = False,
    ) -> None:
        super().__init__()
        self.num_classes = num_classes
        self.embedding_dim = embedding_dim
        self.use_pretrained = use_pretrained

        if use_pretrained:
            try:
                import torchvision.models as models

                backbone = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)
                feature_dim = backbone.fc.in_features
                backbone.fc = nn.Identity()
                self.backbone = backbone
                self.fc_embed = nn.Linear(feature_dim, embedding_dim)
            except ImportError as err:
                raise ImportError(
                    "torchvision is required for pretrained ResNet-18 backbone."
                ) from err
        else:
            self.backbone = nn.Sequential(
                ConvBlock(3, 32),
                ConvBlock(32, 64),
                ConvBlock(64, 128),
                ConvBlock(128, 256),
                nn.AdaptiveAvgPool2d((1, 1)),
                nn.Flatten(),
            )
            self.fc_embed = nn.Linear(256, embedding_dim)

        self.classifier = nn.Linear(embedding_dim, num_classes)

    def forward(
        self,
        x: torch.Tensor,
        return_embedding: bool = False,
    ) -> torch.Tensor | tuple[torch.Tensor, torch.Tensor]:
        """
        Forward pass.

        Parameters
        ----------
        x:
            Input tensor of shape (B, 3, H, W).
        return_embedding:
            If True, returns (logits, embedding). Otherwise returns logits.

        """
        features = self.backbone(x)
        if self.use_pretrained and features.ndim > 2:
            features = torch.flatten(features, 1)
        embedding = self.fc_embed(features)
        logits = self.classifier(embedding)

        if return_embedding:
            return logits, embedding
        return logits

    def get_embedding(self, x: torch.Tensor) -> torch.Tensor:
        """Extract 128-d penultimate embedding."""
        features = self.backbone(x)
        if self.use_pretrained and features.ndim > 2:
            features = torch.flatten(features, 1)
        return self.fc_embed(features)


class AudioEncoder(nn.Module):
    """
    Audio branch encoder for log-mel spectrograms.

    Architecture:
    - 4 Conv blocks on (1, 64, 251) log-mel input: 1 -> 32 -> 64 -> 128 -> 256 channels.
    - Adaptive average pooling to (1, 1).
    - Linear projection to penultimate 128-d embedding.
    - Linear classification head to 2 classes (background, gunshot).
    """

    def __init__(
        self,
        num_classes: int = 2,
        embedding_dim: int = 128,
        use_pretrained: bool = False,
    ) -> None:
        super().__init__()
        self.num_classes = num_classes
        self.embedding_dim = embedding_dim
        self.use_pretrained = use_pretrained

        if use_pretrained:
            logger.info("Custom AudioEncoder used; pretrained audio backbone is opt-in.")

        self.backbone = nn.Sequential(
            ConvBlock(1, 32),
            ConvBlock(32, 64),
            ConvBlock(64, 128),
            ConvBlock(128, 256),
            nn.AdaptiveAvgPool2d((1, 1)),
            nn.Flatten(),
        )
        self.fc_embed = nn.Linear(256, embedding_dim)
        self.classifier = nn.Linear(embedding_dim, num_classes)

    def forward(
        self,
        x: torch.Tensor,
        return_embedding: bool = False,
    ) -> torch.Tensor | tuple[torch.Tensor, torch.Tensor]:
        """
        Forward pass.

        Parameters
        ----------
        x:
            Input log-mel spectrogram of shape (B, 1, 64, 251).
        return_embedding:
            If True, returns (logits, embedding). Otherwise returns logits.

        """
        features = self.backbone(x)
        embedding = self.fc_embed(features)
        logits = self.classifier(embedding)

        if return_embedding:
            return logits, embedding
        return logits

    def get_embedding(self, x: torch.Tensor) -> torch.Tensor:
        """Extract 128-d penultimate embedding."""
        features = self.backbone(x)
        return self.fc_embed(features)

from __future__ import annotations

import logging
from pathlib import Path

import numpy as np
import pandas as pd
import torch
from PIL import Image
from torch.utils.data import Dataset

from src.models import IMAGE_CLASS_TO_IDX

logger = logging.getLogger(__name__)

# Standard ImageNet normalization parameters
IMAGENET_MEAN = np.array([0.485, 0.456, 0.406], dtype=np.float32)
IMAGENET_STD = np.array([0.229, 0.224, 0.225], dtype=np.float32)


def preprocess_image(
    image: Image.Image,
    target_size: tuple[int, int] = (224, 224),
    is_train: bool = False,
    seed: int | None = None,
) -> torch.Tensor:
    """Resize, augment, and normalize PIL Image to (3, H, W) float32 tensor."""
    img = image.convert("RGB")
    if img.size != target_size:
        img = img.resize(target_size, Image.Resampling.BILINEAR)

    arr = np.array(img, dtype=np.float32) / 255.0

    # Data augmentation on training split only
    if is_train:
        # Random horizontal flip
        rng = np.random.default_rng(seed)
        if rng.random() > 0.5:
            arr = np.fliplr(arr)

    # Normalize (H, W, C)
    arr = (arr - IMAGENET_MEAN) / IMAGENET_STD
    # Convert to (C, H, W)
    tensor = torch.from_numpy(arr.transpose(2, 0, 1).copy())
    return tensor


class ImageDataset(Dataset):
    """
    PyTorch Dataset reading images defined in a GuardianEye manifest DataFrame.

    Parameters
    ----------
    manifest_df:
        DataFrame containing manifest rows for image files.
    data_root:
        Path to the root data directory.
    target_size:
        Tuple of (height, width) for image resizing (default (224, 224)).
    is_train:
        Whether training augmentations should be enabled.

    """

    def __init__(
        self,
        manifest_df: pd.DataFrame,
        data_root: Path | str,
        target_size: tuple[int, int] = (224, 224),
        is_train: bool = False,
    ) -> None:
        super().__init__()
        self.data_root = Path(data_root)
        self.target_size = target_size
        self.is_train = is_train

        # Filter strictly to image modality rows
        if "modality" in manifest_df.columns:
            self.df = manifest_df[manifest_df["modality"] == "image"].reset_index(
                names="manifest_idx"
            )
        else:
            self.df = manifest_df.reset_index(names="manifest_idx")

    def __len__(self) -> int:
        return len(self.df)

    def __getitem__(self, idx: int) -> dict[str, Any]:
        row = self.df.iloc[idx]
        rel_path = row["path"]
        full_path = self.data_root / rel_path

        label_str = row["label"]
        if label_str not in IMAGE_CLASS_TO_IDX:
            raise ValueError(f"Unknown image class label: {label_str}")
        label_idx = IMAGE_CLASS_TO_IDX[label_str]

        manifest_idx = int(row.get("manifest_idx", idx))
        view = str(row.get("view", "unknown"))

        try:
            with Image.open(full_path) as img:
                tensor = preprocess_image(
                    img,
                    target_size=self.target_size,
                    is_train=self.is_train,
                )
        except Exception as exc:
            logger.error("Failed to load image %s: %s", full_path, exc)
            raise

        return {
            "image": tensor,
            "label": torch.tensor(label_idx, dtype=torch.long),
            "manifest_idx": manifest_idx,
            "path": rel_path,
            "view": view,
            "label_str": label_str,
        }
  
===== src\image\evaluate.py =====  
"""
Evaluation routine for GuardianEye image branch.

Computes:
- Overall accuracy and macro F1
- Per-class precision, recall, and F1 (human, vehicle, animal, empty)
- Per-view breakdown: aerial_thermal vs camera_trap
- Strict zero-denominator honesty: undefined metrics are stored as None/null,
  views or classes with 0 test instances are recorded as NOT YET RUN.
"""

from __future__ import annotations

import logging
from pathlib import Path
from typing import Any

import pandas as pd
import torch
from torch.utils.data import DataLoader

from src.evaluation.metrics import (
    compute_image_view_metrics,
    compute_multiclass_image_metrics,
)
from src.image.dataset import ImageDataset
from src.models import IMAGE_CLASSES

logger = logging.getLogger(__name__)


def evaluate_image_model(
    model: torch.nn.Module,
    test_df: pd.DataFrame,
    data_root: Path | str,
    device: torch.device,
    batch_size: int = 32,
) -> dict[str, Any]:
    """
    Evaluate trained ImageEncoder exclusively on test_df.

    Returns dictionary formatted for serialization to image_metrics.json.
    """
    model.eval()

    if len(test_df) == 0:
        logger.warning("Empty test DataFrame passed to evaluate_image_model.")
        return {
            "status": "NOT YET RUN",
            "reason": "Test set contains 0 samples.",
            "overall": {
                "count": 0,
                "accuracy": None,
                "f1_macro": None,
                "per_class": {
                    c: {"status": "NOT YET RUN", "reason": "No test samples."}
                    for c in IMAGE_CLASSES
                },
            },
            "by_view": {
                "aerial_thermal": {
                    "status": "NOT YET RUN",
                    "reason": "No test samples.",
                },
                "camera_trap": {
                    "status": "NOT YET RUN",
                    "reason": "No test samples.",
                },
            },
        }

    dataset = ImageDataset(test_df, data_root=data_root, is_train=False)
    loader = DataLoader(dataset, batch_size=batch_size, shuffle=False, num_workers=0)

    all_preds: list[int] = []
    all_targets: list[int] = []
    all_views: list[str] = []

    with torch.no_grad():
        for batch in loader:
            imgs = batch["image"].to(device)
            labels = batch["label"]
            views = batch["view"]

            logits = model(imgs, return_embedding=False)
            preds = torch.argmax(logits, dim=-1).cpu().tolist()

            all_preds.extend(preds)
            all_targets.extend(labels.tolist())
            all_views.extend(views)

    # Compute overall multiclass metrics
    overall_metrics = compute_multiclass_image_metrics(
        y_true=all_targets,
        y_pred=all_preds,
        class_names=IMAGE_CLASSES,
    )

    # Compute per-view breakdown
    eval_df = pd.DataFrame(
        {
            "label_idx": all_targets,
            "pred_idx": all_preds,
            "view": all_views,
        }
    )
    view_metrics = compute_image_view_metrics(eval_df, class_names=IMAGE_CLASSES)

    return {
        "status": "OK",
        "count": len(all_targets),
        "overall": overall_metrics,
        "by_view": view_metrics,
    }
  
===== src\image\train.py =====  
"""
Training routine for GuardianEye image branch.

Features:
- Class-weighted CrossEntropyLoss: w_c = N / (K * n_c), missing classes get weight 0.0
- Epoch checkpointing with atomic saving and resumption
- Model selection via validation split macro F1
- Resumable optimizer, epoch, config, and seed tracking
"""

from __future__ import annotations

import logging
from pathlib import Path
from typing import Any

import numpy as np
import pandas as pd
import torch
import torch.nn as nn
from torch.utils.data import DataLoader

from src.checkpoint import find_latest_checkpoint, load_checkpoint, save_checkpoint
from src.config import GuardianEyeConfig
from src.evaluation.metrics import compute_multiclass_image_metrics
from src.image.dataset import ImageDataset
from src.models import IMAGE_CLASSES, ImageEncoder

logger = logging.getLogger(__name__)


def compute_image_class_weights(
    df: pd.DataFrame,
    class_names: list[str] = IMAGE_CLASSES,
) -> torch.Tensor:
    """
    Compute inverse frequency class weights: w_c = N / (K * n_c).

    If a class has 0 samples, logs a warning and assigns weight 0.0
    to avoid division by zero and degenerate loss behavior.
    """
    k = len(class_names)
    weights = torch.zeros(k, dtype=torch.float32)

    if len(df) == 0:
        logger.warning("Empty training DataFrame provided for class weights.")
        return weights

    counts: dict[str, int] = df["label"].value_counts().to_dict()
    total_samples = len(df)

    for idx, c in enumerate(class_names):
        count = counts.get(c, 0)
        if count == 0:
            logger.warning(
                "Training data has 0 instances of '%s'. Setting weight 0.0.",
                c,
            )
            weights[idx] = 0.0
        else:
            weights[idx] = float(total_samples / (k * count))

    return weights


def train_image_epoch(
    model: nn.Module,
    loader: DataLoader,
    optimizer: torch.optim.Optimizer,
    criterion: nn.Module,
    device: torch.device,
) -> float:
    """Train for a single epoch and return average loss."""
    model.train()
    total_loss = 0.0
    steps = 0

    for batch in loader:
        images = batch["image"].to(device)
        labels = batch["label"].to(device)

        optimizer.zero_grad()
        logits = model(images, return_embedding=False)
        loss = criterion(logits, labels)

        loss.backward()
        optimizer.step()

        total_loss += loss.item()
        steps += 1

    return total_loss / steps if steps > 0 else 0.0


def validate_image_epoch(
    model: nn.Module,
    loader: DataLoader,
    criterion: nn.Module,
    device: torch.device,
) -> tuple[float, float | None]:
    """Validate on validation set; return (val_loss, val_macro_f1)."""
    model.eval()
    total_loss = 0.0
    steps = 0
    all_preds: list[int] = []
    all_targets: list[int] = []

    with torch.no_grad():
        for batch in loader:
            images = batch["image"].to(device)
            labels = batch["label"].to(device)

            logits = model(images, return_embedding=False)
            loss = criterion(logits, labels)

            total_loss += loss.item()
            steps += 1

            preds = torch.argmax(logits, dim=-1).cpu().tolist()
            all_preds.extend(preds)
            all_targets.extend(labels.cpu().tolist())

    val_loss = total_loss / steps if steps > 0 else 0.0
    metrics = compute_multiclass_image_metrics(
        all_targets, all_preds, class_names=IMAGE_CLASSES
    )
    val_f1 = metrics.get("f1_macro")

    return val_loss, val_f1


def train_image_model(
    train_df: pd.DataFrame,
    val_df: pd.DataFrame,
    data_root: Path | str,
    cfg: GuardianEyeConfig,
    seed: int,
    device: torch.device,
    checkpoint_dir: Path | str,
    epochs: int | None = None,
    batch_size: int | None = None,
    resume: bool = True,
) -> tuple[ImageEncoder, dict[str, Any]]:
    """Train ImageEncoder on train_df, validate on val_df, and save checkpoints."""
    torch.manual_seed(seed)
    np.random.seed(seed)

    ckpt_dir = Path(checkpoint_dir)
    ckpt_dir.mkdir(parents=True, exist_ok=True)

    n_epochs = epochs or cfg.image.epochs
    bs = batch_size or cfg.image.batch_size

    # Instantiate model
    model = ImageEncoder(
        num_classes=cfg.image.num_classes,
        embedding_dim=cfg.image.embedding_dim,
        use_pretrained=cfg.image.pretrained,
    ).to(device)

    optimizer = torch.optim.AdamW(
        model.parameters(),
        lr=cfg.image.lr,
        weight_decay=cfg.image.weight_decay,
    )

    # Compute class weights
    class_weights = compute_image_class_weights(train_df, IMAGE_CLASSES).to(device)
    criterion = nn.CrossEntropyLoss(weight=class_weights)

    # Prepare datasets and loaders
    train_dataset = ImageDataset(train_df, data_root=data_root, is_train=True)
    val_dataset = ImageDataset(val_df, data_root=data_root, is_train=False)

    train_loader = DataLoader(
        train_dataset, batch_size=bs, shuffle=True, num_workers=0
    )
    val_loader = DataLoader(val_dataset, batch_size=bs, shuffle=False, num_workers=0)

    start_epoch = 0
    best_val_metric: float = -1.0
    history: list[dict[str, Any]] = []

    # Check for resumable checkpoint
    if resume:
        latest = find_latest_checkpoint(ckpt_dir)
        if latest is not None:
            state = load_checkpoint(latest)
            model.load_state_dict(state["model_state"])
            optimizer.load_state_dict(state["optimizer_state"])
            start_epoch = state["epoch"] + 1
            best_val_metric = state.get("best_val_metric", -1.0)
            logger.info("Resumed image training from epoch %d", state["epoch"])

    for epoch in range(start_epoch, n_epochs):
        train_loss = train_image_epoch(
            model, train_loader, optimizer, criterion, device
        )
        val_loss, val_f1 = validate_image_epoch(
            model, val_loader, criterion, device
        )

        metric_for_selection = val_f1 if val_f1 is not None else -val_loss
        is_best = metric_for_selection > best_val_metric
        if is_best:
            best_val_metric = metric_for_selection

        logger.info(
            "Epoch [%d/%d] Train Loss: %.4f | Val Loss: %.4f | Val F1: %s (best: %.4f)",
            epoch,
            n_epochs - 1,
            train_loss,
            val_loss,
            f"{val_f1:.4f}" if val_f1 is not None else "null",
            best_val_metric,
        )

        state = {
            "model_state": model.state_dict(),
            "optimizer_state": optimizer.state_dict(),
            "epoch": epoch,
            "config": cfg.model_dump(),
            "seed": seed,
            "best_val_metric": best_val_metric,
            "metrics": {
                "train_loss": train_loss,
                "val_loss": val_loss,
                "val_f1": val_f1,
            },
        }

        # Save regular epoch checkpoint
        save_checkpoint(state, ckpt_dir, epoch)

        # Save best checkpoint
        if is_best:
            save_checkpoint(state, ckpt_dir, epoch, filename="best_model.pt")

        history.append(
            {
                "epoch": epoch,
                "train_loss": train_loss,
                "val_loss": val_loss,
                "val_f1": val_f1,
            }
        )

    # Load best checkpoint if saved
    best_path = ckpt_dir / "best_model.pt"
    if best_path.exists():
        best_state = load_checkpoint(best_path)
        model.load_state_dict(best_state["model_state"])
        logger.info("Loaded best image model from %s", best_path)

    return model, {"history": history, "best_val_metric": best_val_metric}

===== src\checkpoint.py =====  
"""
Shared checkpointing utilities for GuardianEye training modules.

Convention
----------
All training scripts in later phases **must** use these helpers to ensure a
consistent checkpoint format and safe atomic writes.

Checkpoint format
-----------------
Each checkpoint is a ``dict`` saved with ``torch.save`` containing at minimum:

``model_state``
    ``model.state_dict()`` — the model weights.
``optimizer_state``
    ``optimizer.state_dict()`` — the optimiser state.
``epoch``
    Integer epoch index (0-based) that just completed.
``config``
    Serialisable snapshot of the training configuration (e.g. a
    ``GuardianEyeConfig.model_dump()`` dict).
``seed``
    Integer random seed used for this run.

Optional keys (include when applicable):
``scheduler_state``
    ``scheduler.state_dict()`` for LR schedulers.
``scaler_state``
    ``scaler.state_dict()`` for ``torch.cuda.amp.GradScaler``.

Naming convention
-----------------
Checkpoints are stored under ``{results_root}/checkpoints/{prefix}/`` and
follow the pattern ``epoch_{epoch:04d}.pt``.  The *latest* checkpoint for a
given prefix is the one with the highest epoch number.

Atomic writes
-------------
Each checkpoint is first written to a ``.tmp`` file alongside the target path
and then renamed, so an interrupted write never corrupts the previous saved
state.

Usage example (in a future training module)
-------------------------------------------
>>> from src.checkpoint import save_checkpoint, find_latest_checkpoint, load_checkpoint
>>> ckpt_dir = cfg.paths.results_root / "checkpoints" / "image_branch"
>>>
>>> # Resume if possible
>>> latest = find_latest_checkpoint(ckpt_dir)
>>> start_epoch = 0
>>> if latest:
...     state = load_checkpoint(latest)
...     model.load_state_dict(state["model_state"])
...     optimizer.load_state_dict(state["optimizer_state"])
...     start_epoch = state["epoch"] + 1
...     logger.info("Resumed from epoch %d", state["epoch"])
>>> else:
...     logger.info("Starting training from scratch")
>>>
>>> for epoch in range(start_epoch, cfg.image.epochs):
...     # ... training loop ...
...     save_checkpoint(
...         state={
...             "model_state": model.state_dict(),
...             "optimizer_state": optimizer.state_dict(),
...             "epoch": epoch,
...             "config": cfg.model_dump(),
...             "seed": cfg.reproducibility.seeds[0],
...         },
...         checkpoint_dir=ckpt_dir,
...         epoch=epoch,
...     )
"""

from __future__ import annotations

import logging
import re
from pathlib import Path
from typing import Any

logger = logging.getLogger(__name__)

_EPOCH_RE = re.compile(r"^epoch_(\d{4,})\.pt$")


def save_checkpoint(
    state: dict[str, Any],
    checkpoint_dir: Path | str,
    epoch: int,
    filename: str | None = None,
) -> Path:
    """
    Save a training checkpoint atomically.

    The checkpoint is written to a temporary file first, then renamed to the
    final path.  This ensures that an interrupted write does not corrupt the
    previous checkpoint.

    Parameters
    ----------
    state:
        Dictionary containing at least ``model_state``, ``optimizer_state``,
        ``epoch``, ``config``, and ``seed``.
    checkpoint_dir:
        Directory in which to save the checkpoint.  Created if absent.
    epoch:
        Zero-based epoch index that just completed.
    filename:
        Optional filename. If not provided, defaults to ``epoch_{epoch:04d}.pt``.

    Returns
    -------
    Path
        Path to the saved checkpoint file.

    Raises
    ------
    ValueError
        If required keys are missing from ``state``.

    """
    import torch  # deferred import — keeps CPU-only imports fast

    _validate_state(state)

    ckpt_dir = Path(checkpoint_dir)
    ckpt_dir.mkdir(parents=True, exist_ok=True)

    if filename is not None:
        target = ckpt_dir / filename
    else:
        target = ckpt_dir / f"epoch_{epoch:04d}.pt"
    tmp = target.with_suffix(".tmp")

    torch.save(state, tmp)
    tmp.replace(target)  # atomic overwrite across POSIX and Windows

    logger.info("Checkpoint saved: %s (epoch %d)", target, epoch)
    return target


def load_checkpoint(path: Path | str) -> dict[str, Any]:
    """
    Load a checkpoint from disk.

    Parameters
    ----------
    path:
        Path to a ``.pt`` checkpoint file.

    Returns
    -------
    dict[str, Any]
        The checkpoint state dictionary.

    Raises
    ------
    FileNotFoundError
        If ``path`` does not exist.

    """
    import torch  # deferred import

    ckpt_path = Path(path)
    if not ckpt_path.exists():
        raise FileNotFoundError(f"Checkpoint not found: {ckpt_path}")

    state: dict[str, Any] = torch.load(
        ckpt_path, map_location="cpu", weights_only=False
    )
    logger.info("Checkpoint loaded: %s (epoch %d)", ckpt_path, state.get("epoch", "?"))
    return state


def find_latest_checkpoint(checkpoint_dir: Path | str) -> Path | None:
    """
    Return the path to the most recent checkpoint in a directory.

    Scans ``checkpoint_dir`` for files matching ``epoch_NNNN.pt`` and returns
    the one with the highest epoch number.  Returns ``None`` when the directory
    does not exist or contains no valid checkpoints.

    Parameters
    ----------
    checkpoint_dir:
        Directory to search.

    Returns
    -------
    Path | None
        Path to the latest checkpoint, or ``None``.

    """
    ckpt_dir = Path(checkpoint_dir)
    if not ckpt_dir.is_dir():
        logger.debug("Checkpoint directory not found: %s", ckpt_dir)
        return None

    candidates: list[tuple[int, Path]] = []
    for p in ckpt_dir.iterdir():
        m = _EPOCH_RE.match(p.name)
        if m:
            candidates.append((int(m.group(1)), p))

    if not candidates:
        logger.debug("No checkpoints found in: %s", ckpt_dir)
        return None

    candidates.sort(key=lambda t: t[0])
    latest_epoch, latest_path = candidates[-1]
    logger.info(
        "Latest checkpoint: %s (epoch %d)", latest_path, latest_epoch
    )
    return latest_path


# ---------------------------------------------------------------------------
# Internal helpers
# ---------------------------------------------------------------------------

_REQUIRED_KEYS: frozenset[str] = frozenset(
    {"model_state", "optimizer_state", "epoch", "config", "seed"}
)


def _validate_state(state: dict[str, Any]) -> None:
    """Raise ``ValueError`` if required checkpoint keys are missing."""
    missing = _REQUIRED_KEYS - set(state)
    if missing:
        raise ValueError(
            f"Checkpoint state is missing required keys: {sorted(missing)}"
        )
  
===== src\decisions.py =====  
"""
GuardianEye risk decision rules.

This module contains two pure functions that map (image_label, audio_label)
pairs to a binary suspicious flag and a categorical risk level.

Labels
------
Valid image labels  : ``"human"``, ``"vehicle"``, ``"animal"``, ``"empty"``
Valid audio labels  : ``"gunshot"``, ``"background"``

Risk rules
----------
HIGH   : image ∈ {human, vehicle}  AND  audio == gunshot  → suspicious = 1
MEDIUM : exactly one strong indicator present:
         - image ∈ {human, vehicle}  AND  audio == background
         - image == animal           AND  audio == gunshot
         → suspicious = 0
LOW    : image ∈ {animal, empty}    AND  audio == background
         → suspicious = 0
         (Includes ESC-50 thunderstorm/wind/rain clips that are labelled as
         *background* with a ``noise_tag`` of ``"thunder_wind"``.  Because
         these clips carry no gunshot audio, they are correctly classified LOW.
         The ``noise_tag`` metadata is **not** a positional argument here; it
         is handled upstream in the data pipeline and does not change the
         risk output.)

Vehicle + background policy
----------------------------
A vehicle without gunshot audio is classified MEDIUM, not HIGH.  The presence
of a vehicle alone is a single strong indicator and insufficient evidence for
an immediate alert.

Noise-tag note
--------------
ESC-50 clips tagged as ``thunder_wind`` are kept as ``"background"`` throughout
the pipeline (they are *never* relabelled as ``"gunshot"``).  When paired with
an ``"empty"`` image they produce a LOW risk score, exactly matching the last
row of the required scenario table.  Tests for this scenario pass
``image_label="empty"`` and ``audio_label="background"``; no third argument is
needed.
"""

from __future__ import annotations

_VALID_IMAGE_LABELS: frozenset[str] = frozenset({"human", "vehicle", "animal", "empty"})
_VALID_AUDIO_LABELS: frozenset[str] = frozenset({"gunshot", "background"})

_STRONG_IMAGE: frozenset[str] = frozenset({"human", "vehicle"})


def _validate(image_label: str, audio_label: str) -> None:
    """
    Raise ``ValueError`` when either label is unknown.

    Parameters
    ----------
    image_label:
        Predicted class from the image branch.
    audio_label:
        Predicted class from the audio branch.

    Raises
    ------
    ValueError
        If ``image_label`` or ``audio_label`` is not a recognised value.

    """
    if image_label not in _VALID_IMAGE_LABELS:
        raise ValueError(
            f"Unknown image_label {image_label!r}. "
            f"Must be one of {sorted(_VALID_IMAGE_LABELS)}."
        )
    if audio_label not in _VALID_AUDIO_LABELS:
        raise ValueError(
            f"Unknown audio_label {audio_label!r}. "
            f"Must be one of {sorted(_VALID_AUDIO_LABELS)}."
        )


def suspicious(image_label: str, audio_label: str) -> int:
    """
    Return 1 when the scene is classified as suspicious, else 0.

    A scene is suspicious only when **both** a strong image indicator
    (human or vehicle) and a gunshot audio signal are present simultaneously.

    Parameters
    ----------
    image_label:
        Predicted label from the image branch.
        One of ``"human"``, ``"vehicle"``, ``"animal"``, ``"empty"``.
    audio_label:
        Predicted label from the audio branch.
        One of ``"gunshot"``, ``"background"``.

    Returns
    -------
    int
        ``1`` if suspicious, ``0`` otherwise.

    Raises
    ------
    ValueError
        If either label is not recognised.

    Examples
    --------
    >>> suspicious("human", "gunshot")
    1
    >>> suspicious("animal", "gunshot")
    0
    >>> suspicious("vehicle", "background")
    0

    """
    _validate(image_label, audio_label)
    return int(image_label in _STRONG_IMAGE and audio_label == "gunshot")


def risk(image_label: str, audio_label: str) -> str:
    """
    Return a categorical risk level for the given label pair.

    Parameters
    ----------
    image_label:
        Predicted label from the image branch.
        One of ``"human"``, ``"vehicle"``, ``"animal"``, ``"empty"``.
    audio_label:
        Predicted label from the audio branch.
        One of ``"gunshot"``, ``"background"``.

    Returns
    -------
    str
        One of ``"HIGH"``, ``"MEDIUM"``, or ``"LOW"``.

    Raises
    ------
    ValueError
        If either label is not recognised.

    Examples
    --------
    >>> risk("human", "gunshot")
    'HIGH'
    >>> risk("animal", "gunshot")
    'MEDIUM'
    >>> risk("empty", "background")
    'LOW'

    """
    _validate(image_label, audio_label)

    # HIGH — both a strong image indicator and gunshot audio
    if image_label in _STRONG_IMAGE and audio_label == "gunshot":
        return "HIGH"

    # MEDIUM — exactly one strong indicator
    if image_label in _STRONG_IMAGE and audio_label == "background":
        return "MEDIUM"
    if image_label == "animal" and audio_label == "gunshot":
        return "MEDIUM"

    # LOW — animal or empty with background (covers thunder_wind tagged clips)
    return "LOW"
  
===== src\bda\mapper_class.py =====  
"""
Class-count mapper for Hadoop-streaming-style BDA jobs.

Reads manifest CSV lines and emits ``(modality, source, label) → 1`` pairs.
Can be used as a standalone script via ``python -m src.bda.mapper_class``
which reads from stdin and writes to stdout, exactly as Hadoop Streaming
would invoke it.
"""

from __future__ import annotations

import csv
import io
import logging
import sys
from collections.abc import Iterator

logger = logging.getLogger(__name__)

# Manifest columns we need — index positions in the CSV header
_COL_MODALITY = "modality"
_COL_SOURCE = "source"
_COL_LABEL = "label"

_REQUIRED_COLUMNS = frozenset({_COL_MODALITY, _COL_SOURCE, _COL_LABEL})


class ClassCountMapper:
    r"""Mapper that emits ``(modality\tsource\tlabel) \t 1`` per manifest row."""

    def __init__(self) -> None:
        self._header: list[str] | None = None
        self._col_indices: dict[str, int] = {}
        self._rows_processed = 0
        self._rows_skipped = 0

    def set_header(self, header_line: str) -> None:
        """
        Parse the CSV header and cache column indices.

        Parameters
        ----------
        header_line:
            The first line of the manifest CSV.

        """
        reader = csv.reader(io.StringIO(header_line.strip()))
        self._header = next(reader, None)
        if self._header is None:
            logger.warning("Empty header line in class-count mapper")
            return
        self._col_indices = {
            col: idx for idx, col in enumerate(self._header)
        }
        missing = _REQUIRED_COLUMNS - set(self._col_indices.keys())
        if missing:
            logger.warning("Manifest header missing columns: %s", sorted(missing))

    def map(self, line: str) -> Iterator[tuple[str, str]]:
        r"""
        Parse a manifest CSV line and emit a key-value pair.

        Parameters
        ----------
        line:
            A single CSV data row (not the header).

        Yields
        ------
        tuple[str, str]
            ``(key, value)`` where key is ``"modality\tsource\tlabel"``
            and value is ``"1"``.

        """
        stripped = line.strip()
        if not stripped:
            return

        reader = csv.reader(io.StringIO(stripped))
        fields = next(reader, None)
        if fields is None:
            self._rows_skipped += 1
            return

        try:
            modality = fields[self._col_indices[_COL_MODALITY]]
            source = fields[self._col_indices[_COL_SOURCE]]
            label = fields[self._col_indices[_COL_LABEL]]
        except (KeyError, IndexError):
            self._rows_skipped += 1
            logger.debug("Skipping malformed row: %s", stripped)
            return

        if not modality or not source or not label:
            self._rows_skipped += 1
            logger.debug("Skipping row with empty fields: %s", stripped)
            return

        self._rows_processed += 1
        key = f"{modality}\t{source}\t{label}"
        yield (key, "1")

    @property
    def rows_processed(self) -> int:
        """Return the number of rows successfully processed."""
        return self._rows_processed

    @property
    def rows_skipped(self) -> int:
        """Return the number of rows skipped due to errors."""
        return self._rows_skipped


def main() -> None:
    """Run as a Hadoop Streaming mapper: read stdin, write to stdout."""
    mapper = ClassCountMapper()
    first_line = True
    for line in sys.stdin:
        if first_line:
            mapper.set_header(line)
            first_line = False
            continue
        for key, value in mapper.map(line):
            sys.stdout.write(f"{key}\t{value}\n")


if __name__ == "__main__":
    main()
  
===== src\bda\mapper_metric.py =====  
"""
Metric mapper for Hadoop-streaming-style BDA jobs.

Reads evaluation metrics JSON entries and emits
``(method, condition, metric_name) → value`` pairs.

Metrics with undefined values (None / null) are **not emitted**, so the
downstream reducer never counts them.

Can be used as a standalone script via ``python -m src.bda.mapper_metric``
which reads JSON lines from stdin and writes to stdout.
"""

from __future__ import annotations

import json
import logging
import sys
from collections.abc import Iterator

logger = logging.getLogger(__name__)

_REQUIRED_KEYS = frozenset({"method", "condition", "metric", "value"})


class MetricMapper:
    r"""Mapper that emits ``(method\tcondition\tmetric) \t value`` per metric entry."""

    def __init__(self) -> None:
        self._rows_processed = 0
        self._rows_skipped = 0

    def map(self, line: str) -> Iterator[tuple[str, str]]:
        r"""
        Parse a JSON metric entry and emit a key-value pair.

        Parameters
        ----------
        line:
            A single JSON object string representing one metric record.

        Yields
        ------
        tuple[str, str]
            ``(key, value)`` where key is ``"method\tcondition\tmetric"``
            and value is a string representation of the numeric metric value.

        """
        stripped = line.strip()
        if not stripped:
            return

        try:
            record = json.loads(stripped)
        except json.JSONDecodeError:
            self._rows_skipped += 1
            logger.debug("Skipping non-JSON line: %s", stripped[:100])
            return

        if not isinstance(record, dict):
            self._rows_skipped += 1
            return

        missing = _REQUIRED_KEYS - set(record.keys())
        if missing:
            self._rows_skipped += 1
            logger.debug("Metric record missing keys: %s", sorted(missing))
            return

        # Skip undefined metrics (zero-denominator honesty)
        value = record["value"]
        if value is None:
            self._rows_skipped += 1
            return

        method = str(record["method"])
        condition = str(record["condition"])
        metric_name = str(record["metric"])

        self._rows_processed += 1
        key = f"{method}\t{condition}\t{metric_name}"
        yield (key, str(value))

    @property
    def rows_processed(self) -> int:
        """Return the number of rows successfully processed."""
        return self._rows_processed

    @property
    def rows_skipped(self) -> int:
        """Return the number of rows skipped due to errors."""
        return self._rows_skipped


def map_from_json_array(json_path: str) -> Iterator[tuple[str, str]]:
    """
    Read a JSON array file and yield all mapper outputs.

    Parameters
    ----------
    json_path:
        Path to a JSON file containing an array of metric records.

    Yields
    ------
    tuple[str, str]
        Key-value pairs from each record.

    """
    mapper = MetricMapper()
    with open(json_path) as fh:
        records = json.load(fh)

    if not isinstance(records, list):
        records = [records]

    for record in records:
        line = json.dumps(record)
        yield from mapper.map(line)


def main() -> None:
    """Run as a Hadoop Streaming mapper: read JSON lines from stdin, write to stdout."""
    mapper = MetricMapper()
    for line in sys.stdin:
        for key, value in mapper.map(line):
            sys.stdout.write(f"{key}\t{value}\n")


if __name__ == "__main__":
    main()

===== src\bda\reducer_metric.py =====  
"""
Metric reducer for Hadoop-streaming-style BDA jobs.

For each ``(method, condition, metric_name)`` key, computes:

- **n**: count of values
- **mean**: arithmetic mean
- **sample_std**: ``sqrt(sum((x - mean)^2) / (n - 1))`` when n ≥ 2;
  empty string when n < 2

Can be used as a standalone script via ``python -m src.bda.reducer_metric``
which reads sorted tab-separated input from stdin and writes to stdout.
"""

from __future__ import annotations

import logging
import math
import sys
from collections.abc import Iterator

logger = logging.getLogger(__name__)


class MetricReducer:
    """Reducer that computes n, mean, and sample standard deviation for each key."""

    def reduce(self, key: str, values: Iterator[str]) -> Iterator[str]:
        r"""
        Compute summary statistics for a group of metric values.

        Parameters
        ----------
        key:
            The grouping key (``"method\tcondition\tmetric"``).
        values:
            Iterator of string-encoded float values.

        Yields
        ------
        str
            ``"key\tn\tmean\tsample_std"`` line.  ``sample_std`` is empty
            when n < 2.

        """
        nums: list[float] = []
        for v in values:
            try:
                nums.append(float(v.strip()))
            except ValueError:
                logger.debug("Non-numeric value for key %r: %r", key, v)

        n = len(nums)
        if n == 0:
            return

        mean = sum(nums) / n

        if n >= 2:
            variance = sum((x - mean) ** 2 for x in nums) / (n - 1)
            sample_std = str(math.sqrt(variance))
        else:
            sample_std = ""

        yield f"{key}\t{n}\t{mean}\t{sample_std}"


def main() -> None:
    """Run as a Hadoop Streaming reducer: read sorted stdin, write to stdout."""
    reducer = MetricReducer()
    current_key: str | None = None
    current_values: list[str] = []

    for line in sys.stdin:
        stripped = line.strip()
        if not stripped:
            continue
        # The key has 3 tab-separated fields; value is the 4th
        parts = stripped.split("\t")
        if len(parts) < 4:
            continue
        key = "\t".join(parts[:3])
        value = parts[3]

        if current_key is not None and key != current_key:
            for output in reducer.reduce(current_key, iter(current_values)):
                sys.stdout.write(output + "\n")
            current_values = []

        current_key = key
        current_values.append(value)

    # Flush last group
    if current_key is not None and current_values:
        for output in reducer.reduce(current_key, iter(current_values)):
            sys.stdout.write(output + "\n")


if __name__ == "__main__":
    main()

r"""
Summation reducer for Hadoop-streaming-style BDA jobs.

Groups by key and sums integer values.  Used by the class-count and scenario
counting pipelines.

Can be used as a standalone script via ``python -m src.bda.reducer_sum``
which reads tab-separated ``key \t value`` pairs from stdin (pre-sorted by

"""

from __future__ import annotations

import logging
import sys
from collections.abc import Iterator

logger = logging.getLogger(__name__)


class SumReducer:
    """Reducer that sums integer values for each key."""

    def reduce(self, key: str, values: Iterator[str]) -> Iterator[str]:
        r"""
        Sum all values for a given key.

        Parameters
        ----------
        key:
            The grouping key (tab-separated composite key).
        values:
            Iterator of string-encoded integer values.

        Yields
        ------
        str
            ``"key\ttotal"`` line.

        """
        total = 0
        for v in values:
            try:
                total += int(v.strip())
            except ValueError:
                logger.debug("Non-integer value for key %r: %r", key, v)
        yield f"{key}\t{total}"

            continue
        key, value = parts

        if current_key is not None and key != current_key:
            for output in reducer.reduce(current_key, iter(current_values)):
                sys.stdout.write(output + "\n")
            current_values = []

        current_key = key
        current_values.append(value)

    # Flush last group
    if current_key is not None and current_values:
        for output in reducer.reduce(current_key, iter(current_values)):
            sys.stdout.write(output + "\n")

===== src\bda\spark_jobs.py =====  
"""
Optional Spark jobs for GuardianEye BDA module.

All PySpark imports are wrapped in try/except.  If ``pyspark`` is not
installed, every public function returns a status dict with
``{"status": "NOT YET RUN", "reason": "pyspark not installed"}``.

When PySpark is available, three jobs are provided:

1. **manifest_to_parquet** — read manifest CSV, write Parquet.
2. **compute_class_weights** — compute ``w_c = N / (k * n_c)`` per modality.
3. **compute_audio_features** — pandas UDF producing log-mel spectrogram features.
"""

from __future__ import annotations

import logging
from pathlib import Path
from typing import Any

logger = logging.getLogger(__name__)

_NOT_YET_RUN: dict[str, str] = {
    "status": "NOT YET RUN",
    "reason": "pyspark not installed. Install with: pip install 'guardian-eye[spark]'",
}

try:
    from pyspark.sql import SparkSession
    from pyspark.sql import functions as F  # noqa: N812

    PYSPARK_AVAILABLE = True
except ImportError:
    PYSPARK_AVAILABLE = False


def _get_spark_session(app_name: str = "GuardianEye-BDA") -> Any:
    """
    Create or get a local Spark session.

    Parameters
    ----------
    app_name:
        Application name for the Spark session.

    Returns
    -------
    SparkSession
        A local Spark session.

    """
    return (
        SparkSession.builder
        .appName(app_name)
        .master("local[*]")
        .config("spark.driver.memory", "2g")
        .getOrCreate()
    )


def manifest_to_parquet(
    manifest_csv: Path,
    output_path: Path,
) -> dict[str, Any]:
    """
    Read manifest CSV and write it as Parquet.

    Parameters
    ----------
    manifest_csv:
        Path to the manifest CSV file.
    output_path:
        Path to write the Parquet file.

    Returns
    -------
    dict[str, Any]
        Status dict with row count and output path.

    """
    if not PYSPARK_AVAILABLE:
        return dict(_NOT_YET_RUN)

    if not manifest_csv.exists():
        return {
            "status": "NOT YET RUN",
            "reason": f"Manifest CSV not found: {manifest_csv}",
        }

    spark = _get_spark_session()
    try:
        df = spark.read.csv(str(manifest_csv), header=True, inferSchema=True)
        row_count = df.count()
        output_path.parent.mkdir(parents=True, exist_ok=True)
        df.write.mode("overwrite").parquet(str(output_path))
        logger.info("Manifest written to Parquet: %s (%d rows)", output_path, row_count)
        return {
            "status": "OK",
            "output": str(output_path),
            "row_count": row_count,
        }
    finally:
        spark.stop()


def compute_class_weights(
    manifest_csv: Path,
    output_path: Path,
) -> dict[str, Any]:
    """
    Compute class weights ``w_c = N / (k * n_c)`` per modality.

    Parameters
    ----------
    manifest_csv:
        Path to the manifest CSV file.
    output_path:
        Path to write the class-weights Parquet file.

    Returns
    -------
    dict[str, Any]
        Status dict with the computed weights.

    """
    if not PYSPARK_AVAILABLE:
        return dict(_NOT_YET_RUN)

    if not manifest_csv.exists():
        return {
            "status": "NOT YET RUN",
            "reason": f"Manifest CSV not found: {manifest_csv}",
        }

    spark = _get_spark_session()
    try:
        df = spark.read.csv(str(manifest_csv), header=True, inferSchema=True)
        total_rows = df.count()
        if total_rows == 0:
            return {
                "status": "NOT YET RUN",
                "reason": f"Manifest CSV contains 0 data rows: {manifest_csv}",
            }

        # Count per (modality, label)
        counts = df.groupBy("modality", "label").count()

        # Total N per modality and number of distinct classes k per modality
        totals = df.groupBy("modality").agg(
            F.count("*").alias("N"),
            F.countDistinct("label").alias("k"),
        )

        # Join and compute w_c = N / (k * n_c), guarding against zero division
        weights_df = (
            counts
            .join(totals, on="modality")
            .withColumn(
                "weight",
                F.when(
                    (F.col("k") > 0) & (F.col("count") > 0),
                    F.col("N") / (F.col("k") * F.col("count")),
                ).otherwise(0.0),
            )
            .select("modality", "label", "count", "N", "k", "weight")
        )

        output_path.parent.mkdir(parents=True, exist_ok=True)
        weights_df.write.mode("overwrite").parquet(str(output_path))

        # Collect for the status dict
        rows = weights_df.collect()
        weight_records = [
            {
                "modality": r["modality"],
                "label": r["label"],
                "n_c": r["count"],
                "N": r["N"],
                "k": r["k"],
                "weight": round(float(r["weight"]), 6),
            }
            for r in rows
        ]

        logger.info("Class weights computed: %d entries", len(weight_records))
        return {
            "status": "OK",
            "output": str(output_path),
            "weights": weight_records,
        }
    finally:
        spark.stop()


def compute_audio_features(
    manifest_csv: Path,
    output_path: Path,
    data_root: Path | None = None,
) -> dict[str, Any]:
    """
    Compute audio log-mel features using a pandas UDF.

    Parameters
    ----------
    manifest_csv:
        Path to the manifest CSV file.
    output_path:
        Path to write the features Parquet file.
    data_root:
        Root directory for resolving audio file paths.

    Returns
    -------
    dict[str, Any]
        Status dict.

    """
    if not PYSPARK_AVAILABLE:
        return dict(_NOT_YET_RUN)

    if not manifest_csv.exists():
        return {
            "status": "NOT YET RUN",
            "reason": f"Manifest CSV not found: {manifest_csv}",
        }

    spark = _get_spark_session()
    try:
        import pandas as pd
        from pyspark.sql.functions import pandas_udf

        df = spark.read.csv(str(manifest_csv), header=True, inferSchema=True)
        audio_df = df.filter(F.col("modality") == "audio")

        row_count = audio_df.count()
        if row_count == 0:
            return {
                "status": "NOT YET RUN",
                "reason": "No audio rows in manifest.",
            }

        resolved_root_str = str(data_root.resolve()) if data_root else ""

        @pandas_udf("array<float>")
        def extract_logmel_bands_udf(paths: pd.Series) -> pd.Series:
            """Compute 64-band log-mel energy means via pandas UDF."""
            try:
                import torchaudio
                has_torchaudio = True
            except ImportError:
                has_torchaudio = False

            results = []
            for rel_path in paths:
                if not has_torchaudio or not resolved_root_str:
                    results.append([0.0] * 64)
                    continue
                full_path = Path(resolved_root_str) / str(rel_path)
                if not full_path.exists():
                    results.append([0.0] * 64)
                    continue
                try:
                    waveform, sr = torchaudio.load(str(full_path))
                    if sr != 8000:
                        waveform = torchaudio.functional.resample(waveform, sr, 8000)
                    if waveform.shape[0] > 1:
                        waveform = waveform.mean(dim=0, keepdim=True)
                    mel_spec = torchaudio.transforms.MelSpectrogram(
                        sample_rate=8000, n_fft=512, hop_length=128, n_mels=64
                    )(waveform)
                    log_mel = (mel_spec + 1e-6).log()
                    band_means = log_mel.mean(dim=2).squeeze(0).tolist()
                    results.append([float(x) for x in band_means])
                except Exception:
                    results.append([0.0] * 64)
            return pd.Series(results)

        output_path.parent.mkdir(parents=True, exist_ok=True)
        audio_features_df = (
            audio_df
            .withColumn("logmel_features", extract_logmel_bands_udf(F.col("path")))
            .select("path", "source", "label", "split", "logmel_features")
        )
        audio_features_df.write.mode("overwrite").parquet(str(output_path))

        logger.info("Audio features manifest written: %s (%d rows)", output_path, row_count)
        return {
            "status": "OK",
            "output": str(output_path),
            "row_count": row_count,
            "feature_dim": 64,
        }
    finally:
        spark.stop()


def get_spark_status() -> dict[str, Any]:
    """
    Return the availability status of PySpark.

    Returns
    -------
    dict[str, Any]
        Status dict indicating whether PySpark is available.

    """
    if PYSPARK_AVAILABLE:
        return {"status": "OK", "pyspark_available": True}
    return dict(_NOT_YET_RUN)


def run_all_spark_jobs(
    manifest_csv: Path,
    output_dir: Path,
    data_root: Path | None = None,
) -> dict[str, Any]:
    """
    Run all Spark jobs and return a combined status.

    Parameters
    ----------
    manifest_csv:
        Path to the manifest CSV file.
    output_dir:
        Directory to write Spark outputs.
    data_root:
        Root directory for resolving file paths.

    Returns
    -------
    dict[str, Any]
        Combined status for all Spark jobs.

    """
    results: dict[str, Any] = {"spark_available": PYSPARK_AVAILABLE}

    if not PYSPARK_AVAILABLE:
        results["status"] = "NOT YET RUN"
        results["reason"] = _NOT_YET_RUN["reason"]
        return results

    output_dir.mkdir(parents=True, exist_ok=True)

    results["manifest_parquet"] = manifest_to_parquet(
        manifest_csv, output_dir / "manifest.parquet"
    )
    results["class_weights"] = compute_class_weights(
        manifest_csv, output_dir / "class_weights.parquet"
    )
    results["audio_features"] = compute_audio_features(
        manifest_csv, output_dir / "audio_features.parquet", data_root
    )

    # Overall status
    statuses = [
        results["manifest_parquet"].get("status"),
        results["class_weights"].get("status"),
        results["audio_features"].get("status"),
    ]
    if all(s == "OK" for s in statuses):
        results["status"] = "OK"
    else:
        results["status"] = "PARTIAL"
        not_run = [
            k for k, v in results.items()
            if isinstance(v, dict) and v.get("status") != "OK"
        ]
        results["not_run_jobs"] = not_run

    return results

"""
Streaming engine for Hadoop-streaming-style BDA jobs.

If ``HADOOP_HOME`` is set and the ``hadoop`` binary is on PATH, runs
mapper/reducer through the Hadoop Streaming jar.  Otherwise sorts mapper
output locally and pipes through the same reducer.

The engine name is logged for every run:
- ``"hadoop_streaming"`` when using an actual Hadoop installation.
- ``"python_streaming_local"`` when running the pure-Python fallback.
"""

from __future__ import annotations

import json
import logging
import os
import shutil
import subprocess
from pathlib import Path

from src.bda.mapper_class import ClassCountMapper
from src.bda.mapper_metric import MetricMapper
from src.bda.mapper_scenario import ScenarioMapper
from src.bda.reducer_metric import MetricReducer
from src.bda.reducer_sum import SumReducer

logger = logging.getLogger(__name__)

# Type aliases
MapperType = ClassCountMapper | ScenarioMapper | MetricMapper
ReducerType = SumReducer | MetricReducer


def _detect_hadoop() -> tuple[bool, str | None]:
    """
    Detect whether Hadoop is available.

    Returns
    -------
    tuple[bool, str | None]
        ``(is_available, streaming_jar_path)``.

    """
    hadoop_home = os.environ.get("HADOOP_HOME")
    if not hadoop_home:
        return False, None

    hadoop_bin = shutil.which("hadoop")
    if not hadoop_bin:
        logger.info("HADOOP_HOME set but 'hadoop' not on PATH; using local streaming")
        return False, None

    # Try to locate the streaming jar
    tools_lib = Path(hadoop_home) / "share" / "hadoop" / "tools" / "lib"
    jar_candidates = sorted(tools_lib.glob("hadoop-streaming-*.jar"))
    if not jar_candidates:
        logger.info("Hadoop Streaming jar not found in %s; using local streaming", tools_lib)
        return False, None

    jar_path = str(jar_candidates[-1])  # latest version
    logger.info("Detected Hadoop Streaming jar: %s", jar_path)
    return True, jar_path


def _run_hadoop_streaming(
    jar_path: str,
    mapper_module: str,
    reducer_module: str,
    input_path: str,
    output_path: str,
) -> None:
    """
    Run a MapReduce job through Hadoop Streaming.

    Parameters
    ----------
    jar_path:
        Path to the Hadoop Streaming JAR file.
    mapper_module:
        Python module path for the mapper (e.g. ``src.bda.mapper_class``).
    reducer_module:
        Python module path for the reducer (e.g. ``src.bda.reducer_sum``).
    input_path:
        HDFS or local input path.
    output_path:
        HDFS or local output path.

    """
    cmd = [
        "hadoop", "jar", jar_path,
        "-mapper", f"python -m {mapper_module}",
        "-reducer", f"python -m {reducer_module}",
        "-input", input_path,
        "-output", output_path,
    ]
    logger.info("Running Hadoop Streaming: %s", " ".join(cmd))
    subprocess.run(cmd, check=True)  # noqa: S603


def _run_local_streaming_csv(
    mapper: ClassCountMapper | ScenarioMapper,
    reducer: SumReducer,
    input_path: Path,
    output_path: Path,
    header_fields: list[str],
) -> None:
    """
    Run a CSV-based streaming job locally.

    Parameters
    ----------
    mapper:
        An initialized mapper instance.
    reducer:
        An initialized reducer instance.
    input_path:
        Path to the input CSV file.
    output_path:
        Path to write the output CSV file.
    header_fields:
        Column names for the output CSV header (key components + "count").

    """
    # Map phase
    kv_pairs: list[tuple[str, str]] = []

    with input_path.open() as fh:
        header_line = fh.readline()
        mapper.set_header(header_line)
        for line in fh:
            for key, value in mapper.map(line):
                kv_pairs.append((key, value))

    logger.info(
        "Mapper processed %d rows, skipped %d",
        mapper.rows_processed,
        mapper.rows_skipped,
    )

    # Sort phase (simulates Hadoop shuffle/sort)
    kv_pairs.sort(key=lambda x: x[0])

    # Reduce phase
    output_path.parent.mkdir(parents=True, exist_ok=True)
    with output_path.open("w", newline="") as fh:
        # Write header
        fh.write(",".join(header_fields) + "\n")

        if not kv_pairs:
            return

        current_key = kv_pairs[0][0]
        current_values: list[str] = []

        for key, value in kv_pairs:
            if key != current_key:
                for output_line in reducer.reduce(current_key, iter(current_values)):
                    parts = output_line.split("\t")
                    fh.write(",".join(parts) + "\n")
                current_values = []
                current_key = key
            current_values.append(value)

        # Flush last group
        if current_values:
            for output_line in reducer.reduce(current_key, iter(current_values)):
                parts = output_line.split("\t")
                fh.write(",".join(parts) + "\n")


def _run_local_streaming_metrics(
    input_path: Path,
    output_path: Path,
) -> None:
    """
    Run metric streaming job locally from a JSON array file.

    Parameters
    ----------
    input_path:
        Path to the JSON metrics file (array of metric objects).
    output_path:
        Path to write the output CSV file.

    """
    mapper = MetricMapper()
    reducer = MetricReducer()

    # Map phase: read JSON array and emit key-value pairs
    with input_path.open() as fh:
        records = json.load(fh)

    if not isinstance(records, list):
        records = [records]

    kv_pairs: list[tuple[str, str]] = []
    for record in records:
        line = json.dumps(record)
        for key, value in mapper.map(line):
            kv_pairs.append((key, value))

    # Sort phase
    kv_pairs.sort(key=lambda x: x[0])

    # Reduce phase
    output_path.parent.mkdir(parents=True, exist_ok=True)
    with output_path.open("w", newline="") as fh:
        fh.write("method,condition,metric,n,mean,sample_std\n")

        if not kv_pairs:
            return

        current_key = kv_pairs[0][0]
        current_values: list[str] = []

        for key, value in kv_pairs:
            if key != current_key:
                for output_line in reducer.reduce(current_key, iter(current_values)):
                    parts = output_line.split("\t")
                    fh.write(",".join(parts) + "\n")
                current_values = []
                current_key = key
            current_values.append(value)

        if current_values:
            for output_line in reducer.reduce(current_key, iter(current_values)):
                parts = output_line.split("\t")
                fh.write(",".join(parts) + "\n")


def get_engine_name() -> str:
    """
    Return the name of the streaming engine that will be used.

    Returns
    -------
    str
        ``"hadoop_streaming"`` or ``"python_streaming_local"``.

def run_class_counts(
    manifest_path: Path,
    output_path: Path,
) -> dict[str, str | int]:
    """
    Run the class-count streaming job.

    Parameters
    ----------
    manifest_path:
        Path to the manifest CSV file.
    output_path:
        Path to write the output CSV file.

    Returns
    -------
    dict[str, str | int]
        Status information including engine name and row count.

    """
    engine = get_engine_name()
    logger.info("Running class-counts job with engine: %s", engine)

    if not manifest_path.exists():
        logger.warning("Manifest not found: %s", manifest_path)
        return {
            "status": "NOT YET RUN",
            "reason": f"Manifest file not found: {manifest_path}",
            "engine": engine,
        }

    if engine == "hadoop_streaming":
        _, jar_path = _detect_hadoop()
        assert jar_path is not None
        _run_hadoop_streaming(
            jar_path,
            "src.bda.mapper_class",
            "src.bda.reducer_sum",
            str(manifest_path),
            str(output_path),
        )
    else:
        mapper = ClassCountMapper()
        reducer = SumReducer()
        _run_local_streaming_csv(
            mapper,
            reducer,
            manifest_path,
            output_path,
            header_fields=["modality", "source", "label", "count"],
        )

    return {"status": "OK", "engine": engine, "output": str(output_path)}
